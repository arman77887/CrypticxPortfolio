# Arian Islam Nirob — Personal 3D Life Story Portfolio

Production-grade 3D autobiography and interactive memory museum web application built for **Arian Islam Nirob** (Creative Alias: **CrypticX**).

## Features

- **Bilingual Interface**: Seamless switching between English and Bangla across all content.
- **3D Graphics Engine**: Interactive particle scenes and distorted glowing core powered by Three.js and React Three Fiber.
- **AutoPhotoSlider**: Automatic 4-second rotating 3D photo gallery with touch gesture support and fullscreen view.
- **Memory Museum & Albums**: Dynamic masonry layout with category filtering and interactive modal lightbox.
- **Supabase Backend**: PostgreSQL database, Row Level Security (RLS) policies, storage buckets for asset management, and authentication.
- **Protected Admin Panel**: Content management system for dynamic updates to biography, memories, albums, and journey milestones.
